      Spatial mode

      Sweet spot delays and levels each MacBook so both reach you together, and keeps left/right on the correct side. Place the speakers and track yourself with the SyncSpeaker iPhone app.

      Acoustic sync calibration

      Each MacBook plays a short chirp and both listen. This measures the distance between them and trims any leftover playback offset. Run it in a quiet room; run twice to confirm the residual is under 0.5 ms.

      Higher latency survives worse Wi-Fi. Changing it briefly re-syncs playback.
